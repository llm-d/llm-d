# Model Guides

Benchmarked, fully tuned recipes for serving one state-of-the-art model on a specific
accelerator, each composing several [foundation guides](../README.md). See the
[Models overview](../../docs/well-lit-paths/models/README.md) for how they fit together and
which are optimized for agentic workloads.

* [DeepSeek-V4](./deepseek-v4/README.md) - `deepseek-ai/DeepSeek-V4-Pro` on GB200 NVL72.
* [GLM-5.2](./glm-5-2/README.md) - `zai-org/GLM-5.2-FP8` on H200.
* [GLM-5.3-Flash](./glm-5-3-flash/README.md) - `zai-org/GLM-5.3-Flash` on B200.
* [NVIDIA Nemotron 3 Ultra](./nemotron-3-ultra/README.md) - `NVIDIA-Nemotron-3-Ultra-550B` on H200.
* [Qwen3.5-397B](./qwen3-5-397b/README.md) - `Qwen/Qwen3.5-397B-A17B-FP8` on TPU 7x (Torch TPU).
